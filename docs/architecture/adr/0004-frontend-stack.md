# ADR-0004: Стек фронтенда

Статус: Принято  
Дата: 29 июля 2026 года

## Контекст

Фронтенд должен быть строго типизированным и доступным разработчику с небольшим
опытом browser UI. Для MVP важнее предсказуемые соглашения и готовые компоненты,
чем максимальная гибкость экосистемы.

## Решение

- Vue 3 и TypeScript в строгом режиме.
- Vite и Vue Router.
- PrimeVue в styled mode как основной UI toolkit.
- PrimeVue Forms и Zod для состояния и проверки форм.
- `@hey-api/openapi-ts` для Fetch-клиента и схем из OpenAPI.
- TanStack Query for Vue для server state, caching и invalidation.
- Pinia добавляется только при появлении состояния, которое нельзя естественно
  разместить в TanStack Query или локальных компонентах.
- Tailwind CSS на старте не используется; применяются design tokens и тема
  PrimeVue, а также scoped CSS.
- `decimal.js` используется для безопасного представления финансовых значений.
- Для финансовых полей создаётся строковый `DecimalInput`; компоненты,
  преобразующие значение в JavaScript `number`, для таких полей запрещены.
- Приложение является SPA; server-side rendering не требуется.

Диаграммы строятся PrimeVue Chart и Chart.js 4. Для MVP используются прежде
всего doughnut и horizontal bar. Преобразование `Decimal` в `number` допускается
только в презентационном адаптере диаграммы и никогда не участвует в
бизнес-расчётах. Точные labels и tooltips форматируются из исходного `Decimal`.
Каждая canvas-диаграмма имеет доступное табличное представление тех же данных.

## Последствия

- Серверное состояние не дублируется в глобальном client-side store.
- Общие компоненты финансового ввода обязаны сохранять строковое значение.
- UI сначала следует PrimeVue design system; собственный CSS ограничен.
- Frontend bundle обслуживается тем же приложением, что и API.

## Рассмотренные альтернативы

- React отклонён: зрелая экосистема требует большего числа самостоятельных
  решений и создаёт лишнюю сложность для текущего опыта.
- Angular отклонён как избыточно тяжёлый для MVP.
- Svelte отклонён из-за меньшей экосистемы и риска смешения поколений паттернов
  при агентской разработке.
- Tailwind CSS отложен до появления подтверждённой потребности.
