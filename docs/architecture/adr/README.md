# Architecture Decision Records

ADR фиксируют архитектурно значимые решения Family Money. После принятия ADR не
переписывается задним числом: изменение решения оформляется новым ADR, который
заменяет предыдущий.

Статусы:

- `Принято` — решение обязательно для текущей реализации;
- `Заменено` — действует ссылка на более новый ADR;
- `Отклонено` — вариант рассмотрен, но не выбран.
